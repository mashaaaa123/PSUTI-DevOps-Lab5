# Лабораторная работа 5: Каталог артистов и групп

## Описание
Веб-приложение для управления каталогом музыкальных артистов и групп, а также просмотра их событий.

## Технологии
- **Фронтенд:** HTML, CSS, Vanilla JS
- **Бэкенд:** [kazan-events](https://github.com/nelkor/kazan-events) (Docker-образ)
- **База данных:** PostgreSQL + PostGIS
- **Веб-сервер:** Nginx (в качестве reverse-proxy)

## Запуск приложения
1. Склонируйте репозиторий.
2. Убедитесь, что у вас установлен Docker и Docker Compose.
3. Запустите проект командой:
   ```bash
   docker compose up -d
